# Rocketgun

Rocketgun is a 3D shooter game built with Unity in which you use the recoil of your gun to fly around! You will play through different levels in which you'll have to defeat enemies and get to the end. Each will get harder and introduce new mechanics.

![Banner](banner.png)

## How to Play

- Use WASD to move and Space to jump
- Use the mouse to look around and aim
- Click to shoot and use the recoil to fly around

**Play the prototype at https://rocketgun.netlify.app**
